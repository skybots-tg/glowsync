# GlowSync

Замена программы Skydimo для подсветки монитора (протестировано с контроллером **SK0127**, 65 светодиодов, CH340 на COM-порту).
Живёт в трее, окно само никогда не открывается.

## Что умеет

- **Синхронизация с экраном** — DXGI Desktop Duplication, кадр уменьшается на видеокарте, нагрузка на CPU ~0.1%.
  Зоны и гамма 2.2 повторяют Skydimo (сверено с его реальным выводом, расхождение ≤ 2/255).
  Настройки: частота 10–60 к/с, плавность, насыщенность, гамма, глубина захвата, смешивание соседних LED,
  порог чёрного, автоудаление чёрных полос у фильмов (субтитры в полосе не сбивают).
- **Музыка** — звук с устройства воспроизведения (WASAPI loopback, микрофон не нужен): спектр, пульс, VU-метр.
- **Эффекты** — радуга, переливание, дыхание, один цвет, комета.
- **Гаснет вместе с монитором** — двумя независимыми способами:
  1. сигналы Windows о состоянии экрана (console/session display state, monitor power);
  2. опрос самого монитора по DDC/CI (VCP 0xD6) раз в 2 секунды — ловит выключение кнопкой монитора,
     о котором Windows не сообщает вовсе. Монитор, который не отвечает на DDC/CI, никогда не гасит ленту,
     одиночный пропущенный ответ тоже (нужно три подряд).

  Плюс защита от «дребезга»: выключение применяется, если экран погашен дольше 2 секунд; включение — сразу.
  Гаснет также при сне и выключении ПК, опционально — при блокировке (Win+L). Плавное включение/выключение.
- **Ночной режим** — ограничение яркости по расписанию; **баланс белого** R/G/B.
- **Горячие клавиши** (глобальные, настраиваемые) + ненавязчивая подсказка на экране, не забирающая фокус.
- Автопоиск и **автопереподключение** ленты (выдернули USB, сон, занятый порт). Bluetooth-порты не опрашиваются.
- Редактор раскладки (стороны, начало, направление, сдвиг) и тест сторон; протокол Adalight для самодельных лент.
- Импорт настроек Skydimo; кнопка «убрать Skydimo из автозапуска» (с возможностью вернуть).
- Лог ограничен 1 МБ (у Skydimo логи разрастались до 15 ГБ).

## Горячие клавиши по умолчанию (перенесены из Skydimo)

| Действие | Сочетание |
|---|---|
| Вкл/выкл | Ctrl + Alt + Shift + F10 |
| Ярче / темнее | Ctrl + Alt + Shift + ↑ / ↓ |
| Следующий / предыдущий режим | Ctrl + Alt + Shift + → / ← |

## Установка и обновление

```powershell
.\install.ps1
```

Нужен .NET 8 Desktop Runtime. Программа ставится в `%LOCALAPPDATA%\Programs\GlowSync`,
настройки — `%LOCALAPPDATA%\GlowSync\config.json`, лог — `%LOCALAPPDATA%\GlowSync\logs`.

Аргументы: `--autostart` — тихий запуск в трей (так прописан автозапуск), `--exit` — закрыть работающий экземпляр.

## Протокол Skydimo (для справки)

- Порт 115200 8N1. Рукопожатие: отправить `Moni-A`, ответ `SK0127,` + 7 байт серийника + `\r\n`.
- Кадр: `A d a 0x00 <count_hi> <count_lo>` + `count × RGB`. Контроллер SK0127 ждёт ровно 65 светодиодов.

## Разработка

```powershell
dotnet build GlowSync.sln
dotnet build tests -o $env:TEMP\gs-tests; & $env:TEMP\gs-tests\GlowSync.Tests.exe
```

Тесты сверяют раскладку с картами Skydimo из `C:\Program Files (x86)\Skydimo`, импорт реального конфига,
сэмплер — с выводом Skydimo на тестовом градиенте, и прогоняют настоящий захват экрана.

Библиотека Vortice 3.8: обёртка `IDXGIOutput5.DuplicateOutput1` падает с AccessViolation,
поэтому метод вызывается напрямую через vtable (см. `DesktopCapture.DuplicateOutput1`).

`POWERBROADCAST_SETTING` несёт ровно один байт данных после GUID и длины: читать его как 32-битное
значение нельзя — за буфером мусор, и «экран выключен» превращается в «включён»
(см. `SystemEvents.OnPowerSettingChange`).
